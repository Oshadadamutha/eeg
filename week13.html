// Combining spatial feature extraction with recurrent temporal modeling into a unified hybrid deep learning architecture

01 The Motivation

By the end of Phase 2, the thinNet model topped out at 58% validation accuracy on the binary Motor Imagery task. The architecture is excellent at extracting spatial patterns from EEG — where on the scalp the signal comes from — but it treats each trial as a static image.

EEG signals are inherently temporal. The suppression of the mu/beta rhythm (Event-Related Desynchronization) during motor imagery evolves over time — it doesn't appear instantaneously. A purely spatial CNN misses this sequential structure. The fix: add an LSTM layer that reads the CNN's feature maps as a time-ordered sequence.

This integration directly implements the EEGNet-LSTM hybrid described in the Week 11 literature review, which achieved ~86% accuracy — a potential 28-point improvement over the current baseline.

02 Hybrid Architecture Design

The key design principle: EEGNet handles the space, LSTM handles the time. Neither stage bleeds into the other's responsibility.

03 Implementation

The critical engineering challenge is the shape bridge between EEGNet's 4D convolutional output and the 3D sequence input expected by LSTM. The reshaping must preserve temporal ordering.

eegnet_lstm.py — Hybrid ArchitecturePyTorch
class EEGNetLSTM(nn.Module):
    def __init__(self, num_classes=2, lstm_hidden=128, lstm_layers=2):
        super().__init__()

        # Stage 1: EEGNet convolutional backbone
        self.eegnet = EEGNet(num_classes=num_classes)

        # Stage 3: LSTM temporal sequence model
        self.lstm = nn.LSTM(
            input_size=self.eegnet.feature_dim,  # F features per timestep
            hidden_size=lstm_hidden,
            num_layers=lstm_layers,
            batch_first=True,
            dropout=0.3
        )

        # Stage 4: Classifier
        self.fc = nn.Linear(lstm_hidden, num_classes)
        self.drop = nn.Dropout(0.5)

    def forward(self, x):
        # x: (Batch, 1, Channels, Time)
        features = self.eegnet.extract_features(x)
        # features: (B, F, 1, T') after EEGNet conv block

        # Stage 2: Reshape — (B, F, 1, T') → (B, T', F)
        B, F, _, T = features.shape
        seq = features.squeeze(2).permute(0, 2, 1)

        # Stage 3: LSTM — returns (output, (h_n, c_n))
        _, (h_n, _) = self.lstm(seq)
        h_last = h_n[-1]  # Take final layer hidden state

        # Stage 4: Classify
        return self.fc(self.drop(h_last))

04 Design Decisions & Rationale

⚡
EEGNet as Frozen Backbone
Initial experiments pre-train EEGNet, then fine-tune jointly with LSTM. This prevents the LSTM from destabilizing the carefully learned spatial filters.
🎯
Last Hidden State Only
Using h_n[-1] (final LSTM output) rather than the full sequence captures the network's temporal "summary" of the entire trial — what matters at the end of the window.
📐
2 LSTM Layers
Stacking two LSTM layers allows the model to learn hierarchical temporal patterns — first-order rhythmic features at layer 1, higher-order sequences at layer 2.
🛡️
Dropout Between Stages
p=0.3 inside LSTM (between layers) and p=0.5 before classifier. Prevents co-adaptation between spatial CNN features and recurrent temporal patterns.

Week 13 Outcome

The EEGNet-LSTM hybrid architecture is designed and its first prototype is running. By combining EEGNet's well-proven spatial feature extraction with LSTM's sequential memory, the model can now reason about when as well as where — a fundamental capability upgrade over thinNet. Preliminary testing confirms richer feature representations. Full hyperparameter tuning, comparative evaluation, and final accuracy benchmarking are the focus of the next phase.
