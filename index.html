Week 1 – Data Ingestion & Signal Processing Pipeline

Objective: Decode complex physiological EEG datasets and prepare them for deep learning ingestion.

Dataset Challenge

  • Dataset: MindBigData Motor Imagery EEG Dataset
  • Format: MATLAB v7.3 (HDF5 nested structures)
  • Six motor imagery tasks:
Left Right Forward Backward Up Down


File pattern:

MoveSep_session*_sub*_reaching_MI.mat

Custom Data Parser

  • Developed dataLoaderNew.py to parse deeply nested HDF5 MATLAB objects.
  • Extracted tensors in format: (Trials, Time_Samples, Channels).
  • Enabled safe traversal of variable-depth EEG structures.

Tensor Standardization for CNN

  • Standardized EEG data into CNN-ready tensors:
(N, 1, 60, 2500)
  • 60 EEG channels mapped as spatial features.
  • Time samples preserved for temporal convolution.
  • Enabled 2D CNN learning on physiological signals.

Class Balancing

  • Aggregated trials across multiple subjects and sessions.
  • Removed dataset bias by equalizing class representation.
  • Ensured uniform distribution across all six MI classes.

Deep Learning Integration

  • Implemented custom torch.utils.data.Dataset wrapper.
  • Enabled memory-efficient batch streaming to GPU.
  • Pipeline is fully compatible with PyTorch training loops.
