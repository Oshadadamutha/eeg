Dead Channel Detection

Flat lines (amplitude near zero across all time points) indicate disconnected electrodes that should be excluded from training.

Normalization Check

Z-scored channels should lie within [-3, +3]. Values beyond ±4 indicate unfiltered eye blink or muscle artifacts.

Contralateral ERD

Left-hand MI should show desynchronization at C4, Right-hand MI at C3. Confirming this spatial pattern validates the data labels.

# Updated thinNet — adding dropout regularization
class thinNet(nn.Module):
    def __init__(self, num_classes=2, dropout=0.5):
        super().__init__()
        self.dropout = nn.Dropout(p=dropout)
        self.classifier = None

    def forward(self, x):
        x = self.temporal(x)
        x = self.spatial(x)
        x = x.flatten(1)
        x = self.dropout(x)  # ← Added: prevents memorizing noise
        if self.classifier is None:
            self.classifier = nn.Linear(x.shape[1], self.num_classes).to(x.device)
        return self.classifier(x)
