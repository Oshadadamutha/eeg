The Pivot

Acknowledging that "Cross-Session Transfer" requires advanced techniques (like Domain Adaptation or Transfer Learning) beyond the scope of this sprint, I pivoted to evaluating the model's ability to classify motor imagery within the general distribution of the subject's data.

Refactoring: manualGS_new.py

I rewrote the entire training pipeline to implement Global Randomized Splitting with strict data hygiene.

1. Global Shuffling

Instead of loading by folder, I loaded all available .mat files into a massive tensor and applied a cryptographically secure shuffle.

# Load EVERYTHING -> Shuffle -> Split
dataset = ConcatDataset(all_datasets)
loader = DataLoader(dataset, batch_size=512, shuffle=True) # Global Mix

2. Preventing Data Leakage

A common pitfall is normalizing data before splitting. This leaks statistics (mean/std) from the test set into the training set. I implemented a strict "Fit on Train, Apply to Test" logic.

# CORRECT Normalization: Calculate stats ONLY on Training Data
mean, std = compute_norm_stats(X_train) 

# Apply those specific stats to both sets
X_train = (X_train - mean) / std
X_test  = (X_test - mean) / std
