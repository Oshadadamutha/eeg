01 Why LSTM for EEG?

EEG signals are time-series data — the brain state at time t is deeply influenced by what happened at t-1, t-2, .... Standard CNNs treat every time window independently. What we need is a model that remembers.

Traditional Recurrent Neural Networks (RNNs) were designed for this, but suffer from a fatal flaw: the vanishing gradient problem. Gradients shrink exponentially as they propagate backward through time, meaning the network can't learn that something that happened 100 timesteps ago is still relevant now.

In 1997, Hochreiter & Schmidhuber introduced LSTM — a gated memory architecture that solves this by explicitly controlling what to remember, what to forget, and what to output at each step.

# LSTM forward pass — conceptual breakdown
# At each timestep t, given input x_t and previous hidden h_{t-1}:

f_t = sigmoid(W_f · [h_prev, x_t] + b_f)   # Forget gate
i_t = sigmoid(W_i · [h_prev, x_t] + b_i)   # Input gate
C̃_t = tanh(W_C · [h_prev, x_t] + b_C)     # Candidate memory

C_t = f_t * C_prev + i_t * C̃_t              # Update cell state

o_t = sigmoid(W_o · [h_prev, x_t] + b_o)   # Output gate
h_t = o_t * tanh(C_t)                      # Hidden state output

02 Anatomy of an LSTM Cell

An LSTM cell has five core components. Unlike a single-weight RNN cell, the LSTM's gating mechanism lets it selectively write, erase, and read from its memory.

// LSTM Cell — Internal Structure
🗑️
Forget Gate
Sigmoid output [0,1]. Decides what fraction of the previous cell state to erase. Zero = complete forget.
✍️
Input Gate
Controls which new candidate values to write into memory. Sigmoid × tanh — scales and filters new information.
📤
Output Gate
Determines what portion of the updated cell state to expose as the hidden state h_t passed forward.
🛣️
Cell State (C_t)
The "highway" of the LSTM. Carries long-term information across timesteps with minimal modification. This is what defeats the vanishing gradient.
📡
Hidden State (h_t)
The "working memory" — the output of the cell at this timestep. Passed to the next cell and used for predictions.

03 RNN vs. LSTM vs. GRU

Three main recurrent architectures exist. For EEG with long dependencies — detecting patterns that span hundreds of milliseconds — LSTM is the right tool.

Standard RNN
Simple hidden state only
Suffers vanishing gradients
Fails on long sequences
Fewest parameters
LSTM ← Our Choice
Cell state + hidden state
3 gates — fine control
Excellent on long seqs
More parameters, more power
GRU (Simplified)
No separate cell state
2 gates — simpler
Good on medium seqs
Faster, less capacity

04 Why LSTM Maps Perfectly to EEG

LSTM has proven itself across every domain of sequential signal processing:

🧠
EEG / BCI Signal Classification
Motor imagery patterns unfold over 500–2500ms. LSTM captures how alpha/beta band suppression evolves in time.
🗣️
Speech Recognition
Phoneme context depends on what came before — LSTM models this temporal dependency naturally.
📈
Time-Series Forecasting
Stock prices, weather, sensor data — LSTM is the standard for predicting future states from past sequences.
💓
Biomedical Signal Analysis
ECG arrhythmia detection, EMG gesture recognition — all benefit from LSTMs ability to remember relevant history.
