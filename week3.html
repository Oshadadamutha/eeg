01 The Philosophy: Constraints Breed Creativity

To combat the massive overfitting from Week 2, a bigger model isn't the answer — a smarter one is. After researching EEGNet and DeepConvNet, a custom variant called thinNet was designed with one guiding principle: decouple what the model is allowed to learn.

⏱️

Temporal Learning

Frequency patterns over time — detecting Alpha (8–12 Hz) and Beta (13–30 Hz) rhythms associated with motor imagery.

🧠

Spatial Learning

Which part of the brain is active — detecting contralateral C3/C4 lateralization for Left vs. Right hand imagery.

By separating these two learning objectives into distinct layers, the model is forced to find physiologically meaningful features rather than memorizing noise.

02 Architecture Deep Dive: thinNet.py

Standard square kernels (e.g., 3×3) were replaced with rectangular kernels that force each layer to learn a specific type of feature. Each layer has a single job.

🌊
Temporal Filter — Layer 1
Conv2d(in=1, out=12, kernel=(1, 11))
Slides only across time. Learns frequency bands (Mu, Beta) per electrode independently.
📍
Spatial Filter — Layer 2
Conv2d(in=12, out=24, kernel=(2, 11), stride=(2, 1))
Mixes adjacent electrodes. Learns WHERE in the scalp the signal comes from.
⚡
Activation
ReLU + BatchNorm after each conv layer
Non-linearity + gradient stabilization.
🎲
Regularization
Dropout(p=0.5)
50% neuron zeroing — prevents co-adaptation and over-reliance on single features.
🎯
Classifier
Linear(flattened → num_classes)
Final prediction layer. Maps learned features to class probabilities.

03 Kernel Design: Why Rectangular?

thinNet.py — Layer definitionsPyTorch
# Layer 1: Temporal Filter — scans time axis only
# Kernel (1, 11): Height=1 (1 channel), Width=11 (time)
# Acts like a Bandpass Filter for brainwave frequencies
nn.Conv2d(in_channels=1, out_channels=12,
         kernel_size=(1, 11), stride=(1, 1))

# Layer 2: Spatial Filter — scans electrode axis
# Kernel (2, 11): combines adjacent channels
# Detects WHERE the signal comes from (C3 vs C4)
nn.Conv2d(in_channels=12, out_channels=24,
         kernel_size=(2, 11), stride=(2, 1))

By strictly defining these kernel dimensions, trainable parameters were reduced by ~70% compared to the Week 2 baseline while maintaining the ability to detect relevant EEG patterns.

04 Regularization Strategy

1 Dropout (p=0.5)

Randomly zeros 50% of neurons during training — forces the network to build redundant representations instead of memorizing specific patterns.

2 Batch Normalization

Normalizes layer inputs to zero mean and unit variance — stabilizes gradient descent and allows higher learning rates.

📈

Week 3 Outcome

thinNet converged faster and the gap between training and validation accuracy narrowed significantly. The model was no longer memorizing noise — it was forcing itself to find structural patterns in the alpha/beta frequency bands over the motor cortex. This is the architecture that all future experiments build on.
