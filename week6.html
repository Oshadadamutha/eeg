Critique of the Old ConvNet

The baseline ConvNet from model_old.py applied standard 2D convolutions with heavy kernels that simultaneously mixed spatial (electrode) and temporal (frequency) information. With approximately 150k parameters, the model was computationally expensive relative to the dataset size and fell into what we termed the "Memorization Trap" — learning session-specific noise artifacts instead of the true Motor Imagery ERD patterns.

The core architectural flaw: Conv2d(1, 20, kernel=(1,31)) followed by Conv2d(20, 40, kernel=(2,1)) — these layers could not cleanly separate "what frequency is present" from "where on the scalp it originates." This entanglement led to fragile representations that failed to generalize across sessions.

thinNet: Decoupled Architecture Design

Inspired by MobileNet's depthwise-separable philosophy and EEGNet's domain-specific spatial filtering, thinNet enforces a strict separation of concerns. The network first understands when something happens, then understands where it happens — never conflating the two.

// thinNet Forward Pass
Input (Batch, 1, Channels, Time)
↓
Temporal Conv Conv2d(1, 20, kernel=(1, 31)) — scans time only
↓
BatchNorm + ELU Normalizes temporal feature maps
↓
Spatial Conv Conv2d(160, 160, kernel=(7, 1)) — scans channels only
↓
AvgPool + Flatten Temporal pooling → feature vector
↓
Dynamic Classifier nn.Linear(x.shape[1], num_classes) — initialized on first pass 
# 🔑 Dynamic initialization — adapts to any input length
class thinNet(nn.Module):
    def __init__(self, num_classes=2):
        super().__init__()
        self.num_classes = num_classes
        self.classifier = None  # Built dynamically

        self.temporal = nn.Sequential(
            nn.Conv2d(1, 20, kernel_size=(1, 31), padding=(0, 15)),
            nn.BatchNorm2d(20), nn.ELU()
        )
        self.spatial = nn.Sequential(
            nn.Conv2d(160, 160, kernel_size=(7, 1)),
            nn.BatchNorm2d(160), nn.ELU(),
            nn.AvgPool2d((1, 4))
        )

    def forward(self, x):
        x = self.temporal(x)
        x = self.spatial(x)
        x = x.flatten(1)
        if self.classifier is None:
            self.classifier = nn.Linear(x.shape[1], self.num_classes).to(x.device)
        return self.classifier(x)

Key Design Decisions & Rationale

⏱

Temporal-First Processing

The 1×31 kernel spans ~62ms at 500Hz — wide enough to capture a full alpha cycle (8Hz) before any spatial mixing occurs.

🧠

Spatial Topology Filter

The 7×1 spatial kernel groups adjacent electrodes, respecting the physical layout of the EEG cap without hardcoding electrode positions.

⚡

Dynamic Linear Layer

Initialized lazily on the first forward pass — allows any input length (2000 or 2500 samples) without rewriting architecture code.

📉

Parameter Efficiency

87% fewer parameters than ConvNet means the model cannot memorize noise — it is forced to learn generalizable EEG features.
