Week 1: Taming High-Dimensional Bio-Signals

Building the EEG Data Ingestion Pipeline

The Challenge: Raw Physiological Data

The foundation of any deep learning project is data, but in the field of Brain-Computer Interfaces (BCI), data doesn't come in neat JPEGs or CSVs. I started with the MindBigData EPOH dataset, a massive collection of brain signals recorded during 6 distinct motor imagery tasks: imagining moving a hand Left, Right, Up, Down, Forward, and Backward.

The raw data was encapsulated in MATLAB’s complex HDF5-based .mat (v7.3) format. My first challenge was bridging the gap between this scientific engineering format and a PyTorch-ready tensor pipeline.

Technical Deep Dive: The Tensor Transformation

The raw EEG data for a single subject contained 60 electrodes (channels) recording at 500Hz for roughly 5 seconds per trial.

  • Raw Input Shape: (N_Trials, 2500_TimeSamples, 60_Channels)
  • Target Output Shape: (N_Trials, 1, 12, 2500)

I made a crucial architectural decision early on to treat EEG signals as "images" to leverage 2D Convolutional Neural Networks. However, instead of using all 60 noisy channels, I implemented a feature selection step based on domain knowledge. Motor imagery is best detected over the sensorimotor cortex.

Code Implementation: dataLoaderNew.py

I wrote a custom Dataset class using h5py to efficiently parse the binary MATLAB files without loading the entire dataset into RAM at once.

# Key components of the Data Ingestion Pipeline

# 1. Channel Selection: Focusing on the Sensorimotor Cortex (C3, C4, Cz, etc.)
SELECTED_CHANNELS = [
    17, 16, 42, 15, 43, 22,  # Cz, C1, C2, C3, C4, CPz
    21, 46, 20, 47, 12, 38   # CP1, CP2, CP3, CP4, FC1, FC2
]

class EEGMotorImageryDataset(Dataset):
    def __init__(self, mat_path, class_name):
        # 2. HDF5 Ingestion
        with h5py.File(mat_path, 'r') as f:
            # Extract raw signal array for the specific movement class
            X = np.array(f['data_struct'][class_name])

        # 3. Dimensionality Reduction (Feature Selection)
        # Reducing noise by selecting only 12 relevant motor cortex channels
        X = X[:, :, SELECTED_CHANNELS]

        # 4. Tensor Reshaping for 2D ConvNets
        # PyTorch Conv2d expects (Batch, Channels, Height, Width)
        # We map EEG Channels -> Height, Time -> Width
        X = X.transpose(0, 2, 1)  # Swap Time and Channels
        X = X[:, None, :, :]      # Add "Color" channel (Batch, 1, 12, 2500)

        self.X = torch.tensor(X, dtype=torch.float32)

Outcome

By the end of Week 1, I had a robust ingestion engine. The pipeline reduced the input data volume by 80% (dropping 48 irrelevant channels) while preserving the critical signal data, significantly speeding up downstream training iterations.
