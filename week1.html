Building the EEG Data Ingestion Pipeline

01 The Challenge: Raw Physiological Data

The foundation of any deep learning project is data, but in Brain-Computer Interfaces (BCI), data doesn't come in neat JPEGs or CSVs. This project begins with the MindBigData EPOH dataset — a massive collection of brain signals recorded during 6 distinct motor imagery tasks: imagining moving a hand Left, Right, Up, Down, Forward, and Backward.

The raw data is stored in MATLAB's complex HDF5-based .mat (v7.3) format. The first challenge was bridging this scientific engineering format and a PyTorch-ready tensor pipeline with no data loss and minimal memory overhead.

02 Technical Deep Dive: Tensor Transformation

Raw EEG data for a single subject contains 60 electrodes recording at 500Hz for roughly 5 seconds per trial — 30,000 values per sample. A key architectural decision was made early: treat EEG signals as "images" to leverage 2D Convolutional Neural Networks.

03 Implementation: dataLoaderNew.py

A custom Dataset class uses h5py to parse binary MATLAB files without loading the entire dataset into RAM — critical for large EEG recordings.

dataLoaderNew.py PyTorch Dataset 
# Channel Selection: Sensorimotor Cortex only
SELECTED_CHANNELS = [
    17, 16, 42, 15, 43, 22,  # Cz, C1, C2, C3, C4, CPz
    21, 46, 20, 47, 12, 38   # CP1, CP2, CP3, CP4, FC1, FC2
]

class EEGMotorImageryDataset(Dataset):
    def __init__(self, mat_path, class_name):
        # HDF5 ingestion — memory-efficient disk access
        with h5py.File(mat_path, 'r') as f:
            X = np.array(f['data_struct'][class_name])

        # Reduce noise: select 12 motor cortex channels
        X = X[:, :, SELECTED_CHANNELS]

        # Reshape for Conv2d: (N, Time, Ch) → (N, 1, Ch, Time)
        X = X.transpose(0, 2, 1)   # Swap Time ↔ Channels
        X = X[:, None, :, :]        # Add "color" dim → (N, 1, 12, 2500)

        self.X = torch.tensor(X, dtype=torch.float32)

A robust ingestion engine is in place. The pipeline reduced input data volume by 80% (dropping 48 irrelevant channels) while preserving the critical sensorimotor signal.
