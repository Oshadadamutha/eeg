Week 02 · Baseline

The Baseline Trap

Overfitting on High-Dimensional Noise

01 The Objective

With data flowing into the GPU, the next step was to establish a Baseline — the Minimum Viable Product of deep learning projects. The goal was to prove that a neural network could learn anything from this EEG data before investing effort in specialized architectures.

This "sanity check" phase is essential: if even an overfit model can't learn the training data, the problem is the data pipeline, not the architecture choice.

02 The Baseline Architecture: convNet

A standard CNN similar to VGG-16 was implemented, adapted for the rectangular shape of EEG data rather than square image inputs.

04 The Overfitting Phenomenon

The results were a classic lesson in the "Curse of Dimensionality." The model memorized training data but completely failed to generalize.

Training Accuracy
99.9%
Model memorized the data perfectly
Validation Accuracy
~25%
Stalled — no real generalization

Because the input vector was so large (30,000 data points per sample) and the dataset size was relatively small (hundreds of trials), the standard convNet simply memorized the Gaussian noise inherent in EEG signals. It was acting as a lookup table, not a feature extractor.

Key Insight — Week 2

This failure was critical — it proved that a generic "computer vision" approach won't work for biological signals. A specialized architecture is needed: one that constrains what the model can learn to force it to find physiologically meaningful patterns (frequency bands, spatial topographies) rather than memorize session-specific noise. This motivates Week 3's thinNet design.
