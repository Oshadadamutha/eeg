Loss Function Fix: NLLLoss → CrossEntropyLoss

The mismatch identified in Week 7 is the single highest-impact fix available. The mathematical error was silently corrupting gradient flow throughout training, costing an estimated 2–4% accuracy.

❌ Before

NLLLoss + Raw Logits

NLLLoss expects log-probabilities. Passing raw logits produces incorrect negative log-likelihood gradients.

→
✓ After

CrossEntropyLoss

Internally applies LogSoftmax + NLLLoss. Accepts raw logits. Mathematically correct gradient flow.

# train_cnn.py — Loss function correction
# BEFORE (Week 7 — incorrect):
criterion = nn.NLLLoss()  # Requires LogSoftmax output!

# AFTER (Week 8 — correct):
criterion = nn.CrossEntropyLoss()  # ✓ Handles softmax internally
